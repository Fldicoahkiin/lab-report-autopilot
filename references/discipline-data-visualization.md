# Data visualization

## Environment route

- Use native Python, spreadsheet software, or the named visualization tool on macOS when supported.
- Use a Windows guest for Windows-only classroom software.
- Record dataset source, row count, fields, preprocessing, tool versions, and output format.

## Build the figure

1. State the analytical question.
2. Inspect the data types and missing values.
3. Apply only the preprocessing needed for the question.
4. Choose a chart whose visual encoding matches the data.
5. Label title, axes, units, categories, and legend.
6. Render the final figure and verify Chinese fonts and symbols.

## Minimum evidence

- Data preview or field description.
- Code or chart settings.
- Rendered chart at readable size.
- A numeric observation from the chart.
- Explanation of why the chart type fits.

## Result analysis

Refer to actual values, ranges, peaks, comparisons, or trends. Distinguish observation from explanation.

Do not call a decorative chart an analysis, use a truncated axis without noting it, infer causation from correlation, or submit a screenshot with missing Chinese glyphs.
